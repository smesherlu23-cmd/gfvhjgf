# Итоги проверки проекта

Проверка от 2026-11-10. Бэкенд собран и запущен на PostgreSQL 16, фронтенд открыт в Chromium. Все пункты ниже воспроизведены.

Фронтенд лежит в `g8cx/pass_manager`, ветка `frontend`. Свежий бэкенд (с шифрованием) лежит в `g8cx/pass_manager`, ветка `main`. В этом репозитории бэкенд более старый, без шифрования.

## Бэкенд

### Важное

1. **Нет авторизации.** `GET /entries` без логина отдаёт все пароли расшифрованными. Шифрование защищает только дамп базы.
2. **Пароль от базы в публичном репозитории** (`pass_manager/src/main/resources/application.properties:4`). Он остался в истории git. Нужно сменить его и брать из переменной окружения.
3. **`PUT /entries/{id}` без `@Valid`.** Тело `{"encryptedPassword":"new"}` обнуляет title, website, username и notes, тело `{}` даёт 500.
4. **Один нерасшифрованный пароль роняет весь `GET /entries`** (500). Так будет со старыми записями и после смены ключа.
5. **Колонки VARCHAR(255).** Пароль длиннее примерно 160 латинских или 80 русских символов (после шифрования) и заметка длиннее 255 символов дают 500.
6. **Не настроен CORS.** Фронтенд с Live Server получает 403.
7. **Нет `spring-boot-maven-plugin`.** Собранный jar не запускается (`no main manifest attribute`).

### Второстепенное

- Отладочные эндпоинты `/hello`, `/status`, `/logins`, `/test-entry`.
- В запросе поле `encryptedPassword` содержит открытый пароль, а в ответе поле называется `password`.
- Ключ шифрования проверяется только при первом сохранении, ошибки ловятся через `catch (Exception e)`.
- `LoginService` занимается записями паролей, имя вводит в заблуждение.
- Нет тестов, POST возвращает 200 вместо 201, DELETE 200 вместо 204.
- `ddl-auto=update` вместо миграций, `show-sql=true`.
- В git попали `.DS_Store` и две папки `.idea`.

## Фронтенд

1. **Sass не собирается.** `_variables.sass:4` объявляет `$backgound-workplace-dark`, а `work_place.sass:24` использует `v.$workplace-backgound-dark`.
2. **Невалидный цвет.** `#10E3fFFB9` в `_variables.sass:13` содержит 9 символов, а HEX-цвет бывает максимум из 8. Исправлять вместе с п.1, иначе после пересборки пропадут рамка и фон кнопок.
3. **`const navigator` и `const navigation`** (`js/scroll_baraban_effector.js:1`, `js/scroll_effector.js:2`) перекрывают `window.navigator` и `window.navigation`. `navigator.clipboard` становится `undefined`.
4. **Эффекты скролла запускаются до загрузки коллекций.** Все коллекции тусклые, нижней тени нет.
5. **Нет адаптива.** На 390px рабочая область сжимается до 0.
6. **`overflow: hidden` на `body`** (`styles.sass:15-18`). На низких экранах Settings и футер обрезаются.
7. **Белый текст на бирюзовых кнопках.** Контраст 2,6:1 при норме 4,5:1.
8. **Вложенность селекторов до 8 уровней.** Стили работают только внутри сайдбара.

## Что сделано хорошо

- Шифрование паролей AES-GCM со случайным nonce, ключ из переменной окружения.
- Отдельный DTO для ответа вместо сущности из базы.
- Валидация создания записи с понятными сообщениями.
- Аккуратный тёмный интерфейс на десктопе.
